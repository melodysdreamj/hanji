# Contributing

Hanji's public repository provides the product source under
[GNU AGPL-3.0](LICENSE) with the
[Sponsor Banner Exception 2.0](LICENSE-EXCEPTION). The project is not currently
accepting external pull requests: its verification infrastructure and release
gate are maintained privately and are required for every product change.

For defects and feature requests, use the public issue templates. Report
security problems through [SECURITY.md](SECURITY.md), not a public issue.
